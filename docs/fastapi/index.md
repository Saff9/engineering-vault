# ⚡ FastAPI Engineering Academy

Welcome to the FastAPI Engineering Academy. This track provides a modern curriculum for building production-grade, high-performance asynchronous APIs and distributed microservices with Python and FastAPI.

---

## 📚 Tracks Inside

### 1. [FastAPI Core Academy](academy/00-Start-Here/Welcome.md)
25 in-depth modules covering:
- **Foundations**: Web & HTTP, Async Python, Modern Python Type Hints
- **FastAPI Core & Pydantic**: Dependency Injection, Pydantic V2 validation & schemas
- **Database Architecture**: SQLAlchemy 2.0 (Async), PostgreSQL, Alembic Migrations
- **Security**: JWT tokens, OAuth2 flows, RBAC authorization, security best practices
- **Testing & Quality**: Pytest, AsyncClient, test containers, automated test suites
- **Scaling & DevOps**: Redis caching, Celery task queues, Docker packaging, CI/CD pipelines
- **Production Architecture**: Hexagonal / Clean Architecture, Observability, Metrics & Tracing

### 2. [Python Standard Libraries Deep Dive](standard-libraries/00-Start-Here/Welcome.md)
Master the underlying Python standard library modules essential for advanced backend engineering:
- `typing`, `functools`, `itertools`, `contextlib`, `dataclasses`
- `asyncio-primitives`, `collections`, `collections-abc`, `pathlib`, `enum`, `logging`
