## 🚀 Navigation & Features

- **Full-Text Search**: Click the search bar or press `S` / `/` to search across all notes instantly.
- **Dark / Light Mode**: Toggle themes using the top-right button.
- **Copy Code Blocks**: Every code snippet includes a 1-click clipboard copy button.
- **Interactive Sidebar**: Expand and navigate between modules and chapters seamlessly.
